# berlipe_MS
### Professional Network Monitor

**Monitoramento de sistema e análise de rede em uma única aplicação.**

---

## Sobre o projeto

O **berlipe_MS** é uma aplicação desktop desenvolvida em Python, projetada para oferecer monitoramento de hardware, análise de conectividade e acompanhamento do desempenho do computador.

Com uma interface moderna e objetiva, o projeto reúne ferramentas essenciais para diagnóstico e visualização de informações do sistema.

Desenvolvido exclusivamente para Windows.

## Funcionalidades

| Módulo | Descrição |
|:---|:---|
| System Monitor | Monitoramento de CPU, GPU, memória RAM e armazenamento. |
| Network Monitor | Análise de latência, perda de pacotes e conectividade. |
| Performance | Acompanhamento de métricas e estatísticas em tempo real. |
| Internet Test | Avaliação da velocidade e desempenho da conexão. |
| DNS Tools | Ferramentas relacionadas à configuração e análise de DNS. |

## Tecnologias

- **Python 3.12+** — Linguagem principal.
- **PySide6** — Desenvolvimento da interface gráfica.
- **PyQtGraph** — Renderização de gráficos e métricas.
- **PyInstaller** — Empacotamento e distribuição.
